# 윤정우 교수 개인 홈페이지 개편 시안

VCC Lab의 화이트·흑백·얇은 구분선 스타일과 어울리게 디자인한 **별도 검토용 사본**입니다. 기존 업로드 자료의 학력·경력·연구·수업·전시·특허 목록 텍스트는 보존했습니다.

## 열어보기
1. 압축을 풀어 폴더를 엽니다.
2. `Home.html` 또는 `index.html`을 더블클릭합니다. 다른 페이지는 상단 메뉴로 이동합니다.
3. 페이지 구성·색상·여백은 `professor-style.css`에서 관리합니다.

## 업로드
GitHub 저장소에 이 폴더 **내부 파일과 사진 전체를 폴더 구조 그대로** 업로드하면 됩니다. 기존 공식 페이지를 덮어쓰지 말고 시안용 별도 저장소에서 먼저 검토하세요.

## 확인 및 조정 필요
- 상단 및 하단의 VCC Lab 링크는 `https://sunnycloudyy.github.io/VCC-lab/`로 설정했습니다. 실제 배포 주소가 다르면 모든 HTML에서 해당 주소를 바꾸세요.
- 원본 `Profile.html`의 존재하지 않는 `0_Home.html` 링크는 `Home.html`로 연결되도록 수정했습니다.
- 기존 Courses 페이지에는 미제공 강의 사진을 나타내는 `Class Photo` 표기가 남아 있습니다. 이미지가 없어서 임의로 채우지 않았습니다.
- 기존 원본에 있던 연구 실적·연도·본문의 사실관계나 맞춤법은 검증·변경하지 않았습니다.
- VCC Lab의 실제 최신 작업본은 전달받지 않아 이전 대화에서 생성한 스타일 파일을 참고했습니다. 최신 스타일과 완전히 똑같게 맞추려면 현재 VCC Lab 폴더를 추가로 비교하세요.
- 교수님 사진·대학 로고 등의 공개 사용 권한은 운영 담당자가 확인하세요.
